# אפליקציית טיול – לימסול 27–30.11.2026

PWA בעברית (עובדת בטלפון, גם בלי אינטרנט) שמלווה את הטיול בזמן אמת:
- מציגה את התוכנית יום-יום, עם ניווט בלחיצה ל-Google Maps.
- עוקבת אחרי המיקום (GPS) ושואלת "הגעתם ל-X? סיימתם?" וגם "הזמן של X עבר – הספקתם?".
- **התאמת תוכנית:** פעילויות שלא הספקתם מועברות ליום/שעה פנויים (תוך כיבוד שעות פתיחה, ימי סגירה, אור יום והזמנות). אפשר גם "מאחרים ב-X דקות".
- **Claude:** בקשה חופשית ("התעייפנו", "יורד גשם") מחזירה הצעות להזזה, דילוג או הוספת אפשרויות. שום שינוי לא מוחל בלי אישור שלכם.
- הכול נשמר מקומית במכשיר.

## הרצה
```bash
cd docs && python3 -m http.server 8000   # ואז http://localhost:8000
```
לשימוש בטלפון צריך HTTPS (GPS ו-service worker דורשים זאת): העלו את התיקייה ל-GitHub Pages / Netlify / Cloudflare Pages, פתחו בטלפון ו"הוסף למסך הבית".
לבדיקה בלי להיות בקפריסין: ⚙️ ← מצב הדגמה (יום ושעה מדומים).

## חיבור Claude – הדרך הפשוטה
ב-⚙️ מדביקים מפתח API מ-console.anthropic.com. המפתח נשמר רק בדפדפן של הטלפון (לא בקוד ולא ב-GitHub) ונשלח ישירות ל-Anthropic. מומלץ לתת למפתח תאריך תפוגה ולמחוק אותו אחרי הטיול.

## חיבור Claude דרך Worker (אופציונלי, מתקדם)
המפתח לא נשמר באפליקציה אלא ב-Worker:
```bash
cd cyprus-worker
npx wrangler deploy
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put APP_TOKEN        # אופציונלי, מונע שימוש לא מורשה
```
ב-⚙️ באפליקציה מדביקים את כתובת ה-Worker (ואת ה-APP_TOKEN). בלי זה ההצעות המקומיות ממשיכות לעבוד.

## קבצים (האפליקציה בתיקיית docs)
- `plan.js` – התוכנית (פריט = יום, שעה, משך, סוג, `fixed` להזמנות/טיסות שלא זזות). ערכו כאן.
- `logic.js` – מנוע ההתאמה (נבדק ב-Node). `app.js` / `index.html` / `styles.css` – ממשק. `sw.js` – offline.
- `cyprus-worker/` – מתווך ל-Claude API.

## מגבלות ידועות
- **קואורדינטות:** המלון והמסעדות אומתו. טירות, קוריון, לפקארה, הנמל ומולוס עדיין משוערות.
- מעקב מיקום עובד רק כשהאפליקציה פתוחה (דפדפן לא עוקב ברקע). התראות מגיעות כשהאפליקציה פתוחה ברקע, לא כשהיא סגורה.
- המנוע המקומי לא מחשב זמני נסיעה בפועל, אלא רק מרווח של 20 דקות; כדאי לבדוק הצעות להעברה בין אזורים רחוקים.
- אין אייקון PNG ל-iOS (יוצג אייקון כללי).
- שעות פתיחה ושעות כפר חג המולד בלפקארה לא אומתו (ראו "לא נבדק" בתוכנית).
