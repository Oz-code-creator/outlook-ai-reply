# אפליקציית טיול – לימסול 27–30.11.2026

PWA בעברית (עובדת בטלפון, גם בלי אינטרנט) שמלווה את הטיול בזמן אמת:
- מציגה את התוכנית יום-יום, עם ניווט בלחיצה ל-Google Maps.
- עוקבת אחרי המיקום (GPS) ושואלת "הגעתם ל-X? סיימתם?" וגם "הזמן של X עבר – הספקתם?".
- **התאמת תוכנית:** פעילויות שלא הספקתם מועברות ליום/שעה פנויים (תוך כיבוד שעות פתיחה, ימי סגירה, אור יום והזמנות). אפשר גם "מאחרים ב-X דקות".
- **Claude:** בקשה חופשית ("התעייפנו", "יורד גשם") מחזירה הצעות להזזה, דילוג או הוספת אפשרויות. שום שינוי לא מוחל בלי אישור שלכם.
- לשוניות 🎒 אריזה ו-✅ משימות: אפשר לסמן, להוסיף ולמחוק פריטים, וגם להקריא בקול (🎤, בעברית; כמה פריטים עם "וגם" ביניהם). ההקלטה דורשת אינטרנט והרשאת מיקרופון.
- 📤 הזמנה: "הזמן את שרית" שולח קישור שמצרף את הטלפון שלה לסנכרון החי.
- הכול נשמר מקומית במכשיר.

## הרצה
```bash
cd docs && python3 -m http.server 8000   # ואז http://localhost:8000
```
לשימוש בטלפון צריך HTTPS (GPS ו-service worker דורשים זאת): העלו את התיקייה ל-GitHub Pages / Netlify / Cloudflare Pages, פתחו בטלפון ו"הוסף למסך הבית".
לבדיקה בלי להיות בקפריסין: ⚙️ ← מצב הדגמה (יום ושעה מדומים).

## סנכרון חי בין הטלפונים (Cloudflare Worker + KV)
1. ב-dash.cloudflare.com: **Workers & Pages** ← **KV** ← **Create** (שם: `cyprus-rooms`).
2. פותחים Worker (אפשר להשתמש בקיים), **Edit code**, מדביקים את `cyprus-worker/sync-worker.js`, **Deploy**.
3. ב-Worker: **Settings** ← **Bindings** ← **Add** ← **KV namespace**; Variable name: `ROOMS`; בוחרים את ה-namespace. **Deploy**.
4. באפליקציה ⚙️ ← סנכרון חי: מדביקים את כתובת ה-Worker, **צור קוד**, **התחל סנכרון**, ואז **הזמן את שרית** (קישור לשליחה).
הגישה לחדר מוגנת בקוד הסודי בלבד. נתונים נמחקים 90 יום אחרי הכתיבה האחרונה. מסונכרנים: רשימות, סימוני פעילויות, הזזות ופעילויות שנוספו. לא מסונכרנים: מפתח ה-API וההגדרות.
בלי קליטה: השינויים נשמרים מקומית ויישלחו כשהחיבור חוזר.

## התראות "הספקתם?" עם כפתורים
- אחרי שעבר זמן של פעילות (10 דק' אחרי הסיום) מגיעה התראה לטלפון עם הכפתורים ✅ הספקנו / ⏭ דילגנו / ✖ ויתרנו. הלחיצה מסמנת בחדר המשותף, וגם אצל שרית. במכשיר שמציג רק 2 כפתורים: ✅ הספקנו / ❌ לא הספקנו, ו"לא הספקנו" פותח התראת המשך עם ↪ הצע העברה / ✖ ויתרנו. מספר הכפתורים שהמכשיר מציג מופיע בהגדרות ליד "פעיל".
- "דילגנו": בפתיחה הבאה של האפליקציה מוצעת העברה ליום ושעה פנויים. "ויתרנו": הפעילות יוצאת מהתוכנית בלי הצעה.
- ההתראות נשלחות לפי שעות התוכנית (לא לפי המיקום), רק לאתרים וקניות. בלי מסעדות ובלי ארוחות בוקר.
- הקמה (פעם אחת, ב-Cloudflare): מדביקים את `cyprus-worker/sync-worker.js` המעודכן ב-Worker; ב-**Settings ← Triggers ← Cron Triggers** מוסיפים `*/5 * * * *`. באפליקציה: ⚙️ ← 🔔 הפעל התראות (בכל טלפון), ואז "שלח התראת בדיקה".
- אם התוכנית ב-`docs/plan.js` משתנה: `node cyprus-worker/build-plan.mjs` ואז להדביק שוב את ה-Worker.
- iPhone: התראות עובדות רק לאפליקציה שמותקנת על המסך הראשי (iOS 16.4 ומעלה).
